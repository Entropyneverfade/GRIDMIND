# GRIDMIND 阶段成果 / Stage report

更新日：2026-10-13。此报告只描述公开代码与可复核的合成测试；外部项目输入、运行表格和项目图均留在用户本机。

## 已实现

1. `gridmind_app/` 负责桌面窗口、图标和EXE构建；`power_ga/` 负责数据接入、Gen0、8760小时运行、适应度/收敛、遗传迭代和结果输出；`project_main.py` 连接前后端。
2. 真实项目适配器识别煤电、燃气、常规水电、抽水蓄能、电池、风电、光伏和生物质；所有源文件只读，成本参数另存可编辑CSV。用户可在窗口选取兼容数据库。
3. 规划基因表示候选容量段的建设与否；种群含全不建与全建基准，使用可行性优先评价、轮盘赌选择、单点交叉、位变异、精英保留、停滞终止和评价缓存。
4. 年度运行保留8760点及每个储能站逐时功率与内部库存。输出一份汇总工作簿、供程序复用的CSV、独立图件文件夹；交互窗口可切换日/周/月/年和任意小时区间。图形源数据与可编辑工程分图存档。
5. Windows单文件EXE已在本机打包并完成隐藏窗口启动检查。EXE未进入公开仓库；仓库提供构建脚本、源码和原创图标。

## 可复核证据

- `python -B -m unittest discover -s tests -q`：13项通过。测试数据均为合成值。
- 八类技术测试检查8760小时逐时平衡、跨日储能库存和充放电互斥。
- 两位候选项目测试独立穷举四种建设组合，并与遗传算法最优方案核对。
- `docs/MATHEMATICS.md` 给出目标、功率平衡、储能状态、水电月预算、可行性与资本回收公式；`release_manifest.json` 记录公开文件SHA256。
- 本地项目运行另进行逐时平衡、储能状态、年度汇总、Excel行数及静态图视觉核验，数值和项目文件不公开。

## 模型边界与下一阶段

目前是确定性单区域研究原型。月水量分配、逐日开机和储能阈值均是透明近似；年度费用使用可编辑的技术基准及独立假设，不是当地采购报价。当前尚无网络潮流、概率可靠性、梯级水电水力耦合或全年全局最优机组组合。后续先改进输入契约和这些物理约束的独立基准测试，再分别增量实现，避免将规则模拟误报为全局最优或将确定性缺供误报为概率性风险。

## 隐私边界

公开副本由显式文件白名单生成，再进行路径与项目标识扫描。仓库只含算法/应用架构代码、合成演示图、合成测试、公式及MIT许可；任何外部项目库及其计算结果均不得复制到公开目录。
